# BNF-Signal · BNF 매매법 자동 알림


### BNF(코테가와 타카시)의 25일선 이격도 역추세 매매법을 한국·미국 주식에 매일 적용해 텔레그램으로 알림을 보내고, 대시보드(GitHub Pages)에 현황을 표시합니다.

## 대시보드: https://okayksh.github.io/BNF-Signal/
## 매매법 정리 노트: BNF-trading-notes (비공개)

# 신호 규칙

| 단계 | 조건 |
| :--- | :--- |
| 🔵 관찰 | 종가가 25EMA 대비 기준 이격도 이하 |
| 🟠 대기 | 최근 10일 안에 이격도 기준 충족 + RSI(14) ≤ 30 |
| 🟢 매수 | 위 조건 + 오늘 MACD 히스토그램이 0선 아래 → 위로 전환 |

# 단계	조건

## 🔵 관찰	종가가 25EMA 대비 기준 이격도 이하
## 🟠 대기	최근 10일 안에 이격도 기준 충족 + RSI(14) ≤ 30
## 🟢 매수	위 조건 + 오늘 MACD 히스토그램이 0선 아래 → 위로 전환

## 이격도 기준(25EMA 대비): 대형주·일반 ETF 상승장 −20% / 하락장 −25%, 코스닥·레버리지 ETF·고변동 −30% / −35% (상승장/하락장 = 코스피 지수 / QQQ가 200일선 위/아래)

## 청산 추적 (매수 신호 이후 자동 추적): 손절 = 최근 10일 최저가 · 익절① = 25EMA 도달 · 익절② = 손익비 2R · 최대 20거래일

# 감시 종목

## 🇰🇷 코스피 시가총액 상위 200 + 코스닥 상위 150
## 🇺🇸 나스닥100 + 주요 ETF(QQQ, SPY, SMH…) + 레버리지/고변동(TQQQ, QLD, SOXL, MSTR, COIN…)

config.json에서 종목·기준값 수정 가능
# 실행 시각 (GitHub Actions, 평일)

한국: 16:40 KST (장 마감 후)
미국: 06:40 KST (미국장 마감 후)
수동 실행: Actions → BNF Signal → Run workflow

# 텔레그램 연결 (1회)

1 텔레그램에서 @BotFather → /newbot → 봇 이름 정하기 → 토큰 복사

2 만든 봇에게 아무 메시지나 보내기

3 브라우저로 https://api.telegram.org/bot<토큰>/getUpdates 열기 → "chat":{"id": 숫자 의 숫자가 채팅 ID

4 이 저장소 Settings → Secrets and variables → Actions → New repository secret

- TELEGRAM_TOKEN = 봇 토큰
- TELEGRAM_CHAT_ID = 채팅 ID

## 실행 시각 (한국 시간 기준)

첫 번째 cron (40 7 * * 1-5):

UTC 기준: 오전 7시 40분 (월~금)

한국 시간(KST) 변환 (+9시간): 오후 4시 40분 (16:40) [월요일~금요일]

설명: 주석에 적힌 대로 한국장 마감 후 (16:40 KST)에 실행됩니다.

번째 cron (40 21 * * 1-5):

UTC 기준: 밤 9시 40분 (월~금)

한국 시간(KST) 변환 (+9시간): 다음 날 오전 6시 40분 (06:40) [화요일~토요일 새벽]

설명: 주석에 적힌 대로 미국장 마감 후 (06:40 KST)에 실행됩니다.


## 요약

한국장 마감 후: 평일(월~금) 오후 4시 40분

미국장 마감 후: 평일 아침(화~토 새벽) 오전 6시 40분

(참고: GitHub Actions 서버의 대기열 상황에 따라 실제 실행 시각은 지정된 시간보다 약 5분~15분 정도 지연될 수 있습니다.)

 # 원본 설정 파일 

  ## on 구문을 보면 다음과 같이 설정 
  
YAML
on:
  schedule:
    - cron: "40 7 * * 1-5"    # 한국장 마감 후 16:40 KST (월~금)
    - cron: "40 21 * * 1-5"   # 미국장 마감 후 06:40 KST (화~토 새벽)
  workflow_dispatch:
    inputs:
      market:
        description: "KR / US / ALL"
        default: "ALL"
GitHub 자체 Cron (schedule): 지정된 시각(UTC 07:40, 21:40)에 깃허브 서버가 스스로 워크플로를 깨워서 bnf_signal.py를 실행합니다.

동작 방식: 코드가 실행되면서 환경 변수로 등록된 TELEGRAM_TOKEN과 TELEGRAM_CHAT_ID를 이용해 텔레그램으로 시그널 결과를 전송합니다.

따라서 cron-job.org 같은 외부 웹훅 설정 없이, 이 YAML 파일 하나만 깃허브에 올려두시면 알아서 정해진 시간에 작동합니다. (단, 앞서 대화에서 다룬 것처럼 깃허브 자체 스케줄러는 서버 상황에 따라 수 분~수십 분의 지연이 발생할 수 있습니다.)
